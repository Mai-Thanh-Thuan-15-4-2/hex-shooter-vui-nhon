# Hex Shooter Vui Nhộn

Game bắn súng lia tâm vui nhộn trên lưới hex, nhẹ, chạy ngay trong trình duyệt.

## Cách chơi
- WASD / Mũi tên: Di chuyển
- Chuột: Lia tâm (crosshair)
- Click chuột: Bắn súng
- Có thanh máu cho player và kẻ địch
- Tiêu diệt quái để lấy điểm

## Deploy
File index.html đã sẵn. Để host trên GitHub Pages:
1. Vào Settings > Pages
2. Source: Deploy from a branch
3. Branch: master / (root)
4. Save

Link sẽ là: https://Mai-Thanh-Thuan-15-4-2.github.io/hex-shooter-vui-nhon/

Chơi local: mở index.html trong trình duyệt.
